1. SEO-01 — one guide page silently overwrote another
------------------------------------------------------
Slugs end in id.slice(-4). Four characters is not enough: sheetz-650 and sheetz-atp-650 both end
"-650" and produced the same URL. Slugs are now assigned once, up front, with collisions resolved
deterministically — the first record by id keeps the existing URL, later ones widen the id
fragment (4 -> 6 -> 8 -> 10 -> full) until unique. If two ever remain equal the generator exits
rather than overwrite a page.

CORRECTION: I first reported 135 collisions. Wrong — that count included the 6,096 records held
back for having no address, which never get a page. Among publishable records there was one, as
the audit said.


2. 22 duplicate records merged and removed

3. RB-07 — the nightly bake reported success while failing
-----------------------------------------------------------
Each step swallows its own failure so the others still run, and whatever succeeded is committed.
That part is correct. But the RUN reported green regardless, which is how a bake applying ZERO
overrides went unnoticed for weeks. Failures are recorded now and a final step fails the job
AFTER the commit, so partial progress still lands and the run goes red.
